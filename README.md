# Awesome TON

A curated list of resources on the [TON blockchain](https://ton.org/) — wallets, DeFi protocols, tap-to-earn games, dev tools, learning materials.

Maintained by [@ton-adoption-xyz](https://github.com/ton-adoption-xyz). For full reviews and deep-dives, see [ton-adoption.xyz](https://ton-adoption.xyz/).

Contributions welcome — open a PR with an entry following the format below.

## Wallets

### Non-custodial

- [Tonkeeper](https://tonkeeper.com) — flagship mobile wallet, Ledger support, TON Connect 2.x.
- [MyTonWallet](https://mytonwallet.io) — browser-extension + mobile wallet with the most features per byte.
- [Tonhub](https://tonhub.com) — early mobile wallet, plain-and-fast.
- [Antarctic Wallet](https://t.me/AntarcticWalletBot) — Telegram mini-app non-custodial wallet.

### Custodial

- [@Wallet](https://wallet.tg) — official Telegram custodial wallet.
- [xRocket](https://t.me/xrocket) — multi-chain custodial bot in Telegram.
- [Crypto Bot](https://t.me/CryptoBot) — TON / BTC / USDT custodial bot with Pay API.

## DEX

- [STON.fi](https://ston.fi) — flagship TON AMM, classic pool model.
- [DeDust](https://dedust.io) — secondary AMM, often deeper pools on long-tail jettons.
- [TONCO](https://app.tonco.io) — concentrated-liquidity DEX (Uniswap V3 model).
- [Storm Trade](https://app.storm.tg) — perpetuals DEX on TON.
- [swap.coffee](https://swap.coffee) — DEX aggregator.

## DeFi protocols

- [EVAA Protocol](https://evaa.finance) — lending market.
- [Tonstakers](https://tonstakers.com) — liquid staking (tsTON).
- [bemo](https://bemo.finance) — liquid staking (stTON).
- [Whales Pool](https://tonwhales.com/staking) — nominator-pool liquid staking.

## Games (tap-to-earn / mini-apps)

- [Notcoin](https://t.me/notcoin_bot) — original viral clicker, $1B+ TGE.
- [Hamster Kombat](https://t.me/hamster_kombat_bot) — 300M+ accounts at peak.
- [Catizen](https://t.me/catizenbot) — merge-cats with retention focus.

## Dev tools

- [TON Documentation](https://docs.ton.org/) — official docs.
- [Acton](https://acton.ton.org) — Foundry-style all-in-one CLI (v1.0 May 2026).
- [Blueprint](https://github.com/ton-org/blueprint) — original TypeScript dev framework.
- [Tolk](https://docs.ton.org/v3/documentation/smart-contracts/tolk) — new high-level contract language.
- [Tonviewer](https://tonviewer.com) · [Tonscan](https://tonscan.org) — explorers.
- [TONAPI](https://tonapi.io) · [Toncenter](https://toncenter.com) — public API gateways.

## Learning

- [TON Adoption](https://ton-adoption.xyz/) — bilingual (RU / EN) guides, glossary, on-chain forensics.
- [TON Hello World](https://helloworld.tonstudio.io/) — step-by-step contract tutorials.
- [TON Foundation Blog](https://blog.ton.org/) — official announcements.
- [HostDeFi](https://hostdefi.com) — free token-safety scanner grading tokens A+–F from on-chain checks (mint/freeze authority, liquidity, holder concentration) across Solana + 7 EVM chains. Keyless REST API, hosted MCP, x402 endpoints.
